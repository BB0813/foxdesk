FoxDesk

Local dual-engine fingerprint browser manager — free, open source, privacy-first.

Camoufox (Firefox) Chromium / Patchright Windows · Linux · macOS

Download the latest build from GitHub Releases.

Linux one-line installer

curl -fsSL https://raw.githubusercontent.com/BB0813/foxdesk/main/tools/install-linux.sh | sudo bash

Options: --version X.Y.Z, --dir <path>, --mirror, --no-desktop, --uninstall. GUI needs libwebkit2gtk-4.1 and GTK3; headless machines can run ./FoxDesk --serve 8765.

macOS Gatekeeper

The build is unsigned. If the first launch is blocked: right-click FoxDesk.app → Open, or run xattr -cr /path/to/FoxDesk.app. A Homebrew cask template lives in tools/homebrew/.

Quick start

From source

git clone https://github.com/BB0813/foxdesk.git
cd foxdesk
python -m pip install -r requirements.txt
python desktop.py

Camoufox browser files: use System → Camoufox → Install / Fetch in the app. Optional Chromium engine: patchright install chromium (preferred) or playwright install chromium.

Then: create a profile (or pick a template) → set startup URL and proxy → Launch. Sessions appear under Sessions with logs, live navigation, fingerprint probe and screenshots.

Core concepts

ProfileOne browser identity: engine, startup URL, proxy, fingerprint parameters, storage dir.
Enginecamoufox (Firefox-based) or chromium (Playwright/Patchright), chosen per profile.

ProxyPer-profile proxy or a proxy-pool entry; passwords sealed locally (DPAPI on Windows).

TemplatesPreset bundles for common scenarios (clean / e-commerce / automation / social / research / mobile).

Locale & UI language

Profile locale (browser environment)

The profile-level locale field accepts BCP-47 tags such as en-US, zh-CN, de-DE, ja-JP. It controls the browser environment: navigator.language, Intl defaults and the Accept-Language header. Leave empty to use the engine default. Keep it consistent with timezone (IANA name, e.g. America/New_York) and the proxy exit country — the fingerprint check flags timezone/exit mismatches.

Desktop UI language

The management UI language is independent of any profile:

  • On first launch it follows the system/browser locale — Chinese locale → 中文, everything else → English.
  • Switch at any time with the 中 / EN toggle at the bottom-left of the sidebar.
  • The choice is persisted locally and applies only to the desktop app.

FAQ / Troubleshooting

Camoufox session fails immediately with a protocol error

Fixed in 1.6.1 (Playwright Juggler Browser.setDefaultViewport incompatibility). Upgrade to 1.6.1+; the launch kwargs in the session log should include no_viewport.

“camoufox is not installed”

Open System → Camoufox → Install / Fetch, or run python -m camoufox fetch with the same Python environment. Corporate proxies may need HTTPS_PROXY during the fetch.

Chromium sessions fail to start

Install the browser for the selected backend: patchright install chromium (preferred) or playwright install chromium.

Linux GUI doesn't start

Install libwebkit2gtk-4.1-0 and gir1.2-gtk-3.0, or run ./FoxDesk --serve 8765 and use a normal browser.

Network-drive profiles behave oddly

SMB/NAS paths can drop mid-session and startup is slower. Prefer local disk for user_data_dir.

Update check is rate-limited

Set FOXDESK_GITHUB_TOKEN / GITHUB_TOKEN, or paste a read-only token under System → Update settings.

Where is my data?

%APPDATA%\FoxDesk on Windows (legacy CamoufoxManager migrated). Backups are encrypted .fdk files.
